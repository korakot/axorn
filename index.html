axorn อักษร

|

อักษรบาลี แบบโรมันและแบบไทย พิมพ์หรือวางข้อความลงในใบลานใบใดก็ได้ อีกใบจะแปลงตามทันที เขียนตามแบบแผนของพระไตรปิฎกฉบับ VRI

ตัวเลือก

ทุกอย่างทำงานในเบราว์เซอร์ของคุณ ข้อความที่พิมพ์ไม่ถูกส่งไปที่ใด และเพราะอักษรไทยไม่มีตัวพิมพ์ใหญ่ ข้อความที่แปลงจากอักษรไทยจึงออกมาเป็นตัวพิมพ์เล็กทั้งหมด

ใช้ในโค้ดของคุณเองได้ทั้ง Python และ JavaScript ผลลัพธ์ตรงกันทุกตัวอักษร
pip install axorn
npm install axorn

หรือนำเข้าในหน้าเว็บโดยตรง รวมถึงใน Claude artifact
import { romanToThai, thaiToRoman } from "https://cdn.jsdelivr.net/npm/axorn/axorn/axorn.js";
