axorn อักษร

Pāli in roman and Thai script. Type or paste into either leaf and the other follows, written the way the VRI Tipiṭaka writes it.

แปลงอักษรบาลี โรมัน ↔ ไทย พิมพ์หรือวางข้อความในใบลานใบใดก็ได้ อีกใบจะแปลงตามทันที

Options

Everything runs in your browser; nothing you type is sent anywhere. Thai has no capital letters, so text converted from Thai comes back in lower case.

Use it in your own code, Python or JavaScript, with the same output from both:
pip install git+https://github.com/korakot/axorn
npm install github:korakot/axorn
